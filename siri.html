Apple won’t let Boss Man install Shortcuts on your phone. Build this once — then voice does the rest.

1. Open Shortcuts
  1. Open the Shortcuts app
  2. Tap + (new shortcut)
  3. Name it Add lawn customer
2. Ask for Input
  1. Add action: Ask for Input
  2. Prompt: Name, phone, address
  3. Input type: Text
3. Send Email
  1. Add action: Send Email (or Open URLs with mailto — see below)
  2. To: lacrosselawnandlandscape@gmail.com
  3. Subject: ADD CUSTOMER (exact)
  4. Body: tap → insert the Provided Input variable
  5. Turn Show Compose Sheet OFF if you want it to send quietly (optional)
4. Add to Siri
  1. Shortcut details (ⓘ) → Add to Siri
  2. Phrase: Add lawn customer
5. Test
  1. Say: Hey Siri, add lawn customer
  2. Speak: Test Customer, 6085550000, 1 Test St
  3. Message Boss Man “test sent” — he’ll confirm when it’s on the list (checks every 15 min)
